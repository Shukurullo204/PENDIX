# PENIX — Backend для платформы объявлений (C2C-Маркетплейс)

Прогрессивный REST API бэкенд для классифайда (доски объявлений), спроектированный по аналогии с современными маркетплейсами. Платформа позволяет пользователям публиковать свои объявления, искать товары по категориям, добавлять их в избранное и общаться в режиме реального времени.

## 🛠 Технологический стек
- **Язык разработки:** Python 3.11+
- **Основной фреймворк:** Django, Django REST Framework (DRF)
- **База данных:** PostgreSQL
- **Дополнительные технологии:** Асинхронное программирование (для чата)

---

## 🏗 Архитектура проекта (Django-приложения)

Проект построен по модульной архитектуре и разделен на изолированные приложения:

* **`users`** — Управление учетными записями. Реализует систему кастомных пользователей, регистрацию, аутентификацию и управление профилями.
* **`ads`** (Объявления) — Ядро платформы. Отвечает за создание, редактирование, модерацию и вывод объявлений пользователей. Оптимизировано для работы с медиа-файлами.
* **`categories`** (Категории) — Система каталога. Реализует сложную структуру вложенных категорий и подкатегорий любой глубины для удобной фильтрации товаров.
* **`chat`** — Модуль асинхронного P2P (Peer-to-Peer) взаимодействия. Реализует систему личных сообщений в реальном времени между покупателем и продавцом.
* **`favorites`** (Избранное) — Сервис для сохранения объявлений. Позволяет пользователям формировать список отслеживаемых товаров.

## 🚀 Установка и запуск проекта локально

Чтобы запустить проект на своем компьютере, выполните следующие шаги:

### 1. Клонирование репозитория
```bash
git clone [https://github.com/Shukurullo204/PENDIX.git](https://github.com/Shukurullo204/PENDIX.git)
cd PENIX

### 2. Настройка виртуального окружения 
python -m venv venv
# Для Windows:
venv\Scripts\activate
# Для macOS/Linux:
source venv/bin/activate


### 3. Установка зависимостей 
pip install -r requirements.txt

### 4. Настройка базы данных и запуск
Настройка базы данных и запуск
python manage.py migrate
python manage.py runserver

После этого API будет доступно по адресу: http://127.0.0.1:8000/
